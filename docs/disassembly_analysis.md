# Анализ ассемблера

Ячейка -4(%rbp) - накопитель (sum), начальное значение 0.
Ячейка -8(%rbp) - счетчик (i), начальное значение 1.
Инструкция jmp .L2 сразу переходит к проверке условия.
cmpl $10 и jle: цикл продолжается, пока i <= 10.
Тело цикла: sum += i; i += 1.
В конце sum копируется в %eax (возвращаемое значение).

Результат: сумма чисел от 1 до 10 = 55.

Эквивалент на Python:

```python
total = 0
i = 1
while i <= 10:
    total += i
    i += 1
```
