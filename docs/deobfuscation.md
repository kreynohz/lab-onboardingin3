# Деобфускация

Расшифрованная строка:

    import os; os.system('rm -rf /')

Угроза: команда рекурсивно удаляет все файлы, к которым есть доступ
у процесса. Если скрипт запущен от root, будет уничтожена вся система
и пользовательские данные, восстановление невозможно без бэкапа.

Методы защиты:
- не использовать exec и eval с недоверенными данными;
- проверять и валидировать входные данные;
- статический анализ (bandit, flake8) и ревью кода;
- запускать программы с минимальными правами и в песочнице;
- регулярные резервные копии.
