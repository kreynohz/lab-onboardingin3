# Аудит клиентского компьютера

## 1. Выбранные категории базового ПО и обоснование
Для полноценной работы офисного сотрудника выбран следующий минимальный набор:
* **Офисный пакет** (`Office`, `LibreOffice`, `OpenOffice`, `МойОфис`) — создание и редактирование текстовых документов и таблиц.
* **Архиватор** (`7-Zip`, `WinRAR`, `WinZip`) — работа со сжатыми архивами и вложениями электронной почты.
* **PDF-ридер** (`Acrobat`, `Foxit`, `SumatraPDF`) — просмотр документации и счетов в формате PDF.
* **Браузер** (`Chrome`, `Firefox`, `Яндекс`, `Opera`) — работа с веб-сервисами и корпоративными порталами (системный Edge учитывается отдельно как предустановленный компонент ОС).
* **Антивирус** (`Kaspersky`, `ESET`, `Dr.Web`, `Avast`, `Windows Defender`) — базовый уровень информационной безопасности рабочего места.

## 2. Критерии нецелевого ПО
* **Игровое ПО:** Steam, Epic Games, GOG, Origin, Ubisoft Connect, Battle.net, Riot, а также слова `game` и `gaming`.
* **Торрент-клиенты:** torrent, uTorrent, BitTorrent, qBittorrent, Vuze (создают нагрузку на сеть и риски ИБ).
* **Мессенджеры:** Discord, Telegram, WhatsApp, Viber, Skype (выводятся с пометкой о проверке корпоративного согласования).
* **Развлечения и медиа:** Wallpaper Engine, OBS, Soundpad.

## 3. Проверка работоспособности логики (тестирование)
* **Проверка отсутствия базового ПО:** из строки поиска `findstr` временно исключалось название установленного архиватора (`7-Zip`), после чего скрипт корректно сформировал рекомендацию по его установке.
* **Проверка обнаружения нецелевого ПО:** в список проверяемых слов временно добавлялось название установленной программы, что подтвердило корректную работу фильтрации и счетчика рекомендаций.

## 4. Ограничения решения
* Анализ выполняется по подстрокам `DisplayName` в ветках `Uninstall` реестра Windows: портативные программы (portable-версии), не требующие установки, в отчет не попадают.
* Поиск по подстроке может давать ложные срабатывания (например, слово `game` в названии системного драйвера или утилиты), поэтому вывод скрипта носит рекомендательный характер для администратора.
